## 一、資料型別基礎

R 的基本型別有優先順序(強制轉型時,低優先度會被轉成高優先度):

```
character > complex > numeric > integer > logical
```

```r
a = 666;        class(a)   # "numeric"
a = 666L;       class(a)   # "integer"，數字後加 L 代表整數
a = TRUE;       class(a)   # "logical"
a = "hello";    class(a)   # "character"
a = 2 + 2i;     class(a)   # "complex"，i 為 √-1
```

常用檢查與轉換函式:

| 函式 | 用途 |
|---|---|
| `class(x)` | 查看物件的類別 |
| `mode(x)` | 查看更底層的儲存模式 |
| `str(x)` | 查看物件結構(型別 + 內容摘要) |
| `is.integer(x)`、`is.character(x)`... | 判斷是否為某型別 |
| `as.integer(x)`、`as.character(x)`... | 轉換成某型別 |

```r
x <- 1:5
mode(x)              # "numeric"
str(x)                # int [1:5] 1 2 3 4 5

x <- as.character(x)  # 轉成字串
mode(x)               # "character"

as.integer(10.10)     # 10，小數會被捨去(非四捨五入)
```

向量建立時,若元素型別不一致,會依上述優先順序自動統一轉型:

```r
c(1, 2, 3)            # 皆為 numeric

c("a", 2, 2 + 2i)      # 都被轉成 character
c(TRUE, 2, 2 + 2i)     # 都被轉成 complex
```

**特殊值**也是型別系統的一部分,計算時要特別注意:

| 值 | 意義 | 範例 |
|---|---|---|
| `NA` | 缺值(Not Available) | `c(1, NA, 3)` |
| `NULL` | 空/不存在(用來清空物件) | `x <- NULL` |
| `Inf` / `-Inf` | 無限大 | `-3 / 0` |
| `NaN` | 不是數字(Not a Number) | `0 / 0`、`Inf - Inf`、`log(-2)` |

```r
is.na(c(1, 2, NA, 4, 5))  # 檢查哪些位置是缺值
mean(c(1, NA, 3))         # NA，預設遇到缺值就整體回傳 NA
mean(c(1, NA, 3), na.rm = TRUE)  # 2，忽略 NA 後計算
```

## 二、數學與四則運算

### 基本四則運算與次方

```r
a <- 2; b <- 3

a + b; a - b; a * b; a / b
a %% b     # 取餘數 -> 2
a %/% b    # 取商數(整數除法) -> 0

a ^ 2      # 次方，等同 b ** 2
sqrt(a)    # 開根號
a ** (1/3) # 開三次方
```

### 常用數學函式

```r
sign(-1)   # 判斷正負：正數回傳 1、0回傳 0、負數回傳 -1
abs(-1)    # 絕對值

log(10)         # 自然對數(以 e 為底)
log(10, base=2) # 以 2 為底，等同 log2(10)
log10(10)       # 以 10 為底
log1p(9)        # log(1+9)，數值接近 0 時精度較好

exp(10)      # e 的次方
expm1(10)    # exp(x) - 1，同樣是為了數值精度而存在
```

> **小技巧**:`log1p()` / `expm1()` 是一組互為反函式的精度優化版本,當 x 非常接近 0 時,直接算 `log(1+x)` 可能因浮點數誤差失真,用 `log1p(x)` 更準確。

## 三、向量:建立、索引、運算

### 建立向量

```r
1:5                   # 1 到 5 的整數序列
seq(1, 5)             # 效果同上
seq(1, 5, 0.3)        # 指定間隔

rep(1, times = 3)                    # 1 1 1
rep(1:3, times = 3, each = 3)        # times 控制整體重複，each 控制單一元素連續重複次數
```

### 具名向量(類似 Python 字典)

```r
x <- c(at = 100, sean = 95, kai = 90)

x[1]        # 取「子向量」(含名稱) -> at: 100
x[[1]]      # 取「純值」            -> 100
x["at"]     # 用名稱取子向量
x[["at"]]   # 用名稱取純值
x[1:2]      # 取多個元素
```

> `[ ]` 和 `[[ ]]` 的差異是 R 初學者常見的困惑點:`[ ]` 保留結構(回傳同型別容器),`[[ ]]` 只取出內部的值本身。

### 索引選取進階(含條件篩選)

```r
x <- (-5) + (0:15)       # -5, -4, ..., 10

x[1]                     # 第 1 個元素
x[1:3]                   # 第 1~3 個元素
x[-(3:6)]                # 排除第 3~6 個元素(負索引 = 排除)
x[x > 0 & x <= 5]        # 邏輯篩選：大於 0 且小於等於 5
x[!(x > 0 & x <= 5)]     # ! 表示反向篩選

x[1:3] <- 100:102             # 直接用索引修改元素
x[(x > 0 & x <= 5)] <- 999    # 也可以用條件篩選來修改元素
```

### 向量的四則運算(逐元素對應)

```r
a <- c(1, 3, 5)
b <- c(2, 4, 6)

a + b; a - b; a * b; a / b   # 都是「對應位置」個別運算
```

### 向量匯總與排序函式

```r
c <- c(3, 5, 9, 4, 1, 2, 6)

length(c)     # 長度
sum(c)        # 加總
prod(c)       # 乘積
cumsum(c)     # 累加：每一步的部分和
cumprod(c)    # 累乘：每一步的部分積
```

**`sort()` / `order()` / `rank()` 的差異**(三者常搞混,合併整理如下):

```r
aa <- c(94, 86, 18, 79, 28)

sort(aa)   # 回傳「排序後的值」            -> 18 28 79 86 94
order(aa)  # 回傳「排序後對應的原始索引」   -> 3  4  5  2  1
rank(aa)   # 回傳「每個原始元素的名次」     -> 5  4  1  3  2
```

> 記憶方式:`sort` 給你「新順序的值」、`order` 給你「怎麼排到新順序的索引」、`rank` 給你「每個舊元素排第幾名」。

### 空向量與自動延長

```r
v <- numeric()   # 建立空向量
v[3] <- 7        # 指定第 3 個位置，前面自動補 NA
v                # NA NA 7
```

## 四、邏輯判斷與字串

### 邏輯運算子

```r
x <- 5; y <- 10

x > 3; x >= 6; x <= 6; x < 3
!(x > 3)          # ! 取反：TRUE 變 FALSE，反之亦然
x %in% c(1:6)     # 檢查是否存在於集合中

x > 4 || y > 10   # || 只比較「單一邏輯值」(短路運算)
x > 4 && y > 10

z <- c(1, 2, 3)
z > 0 & z > -1    # & 逐元素比較整個向量 -> TRUE TRUE TRUE
z > 0 && z > -1   # && 只取向量第一個元素比較 -> TRUE
```

> **常見地雷**:`&`/`|` 是向量化運算(逐一比較每個元素),`&&`/`||` 只看第一個元素且具短路特性。若在 `if()` 條件裡誤用 `&` 處理向量,R 較新版本會直接報錯;處理向量邏輯務必用 `&`,單一條件判斷式(如 if)則用 `&&`。

### 字串操作

```r
a <- "g"
b <- c(1, "x", 2)   # 數字與字串混合，數字被強制轉成字串

paste("Affy", 1:5, sep = "")        # "Affy1" "Affy2" ... "Affy5"
paste(c("X", "Y"), 1:5, sep = "_")  # "X_1" "Y_2" "X_3" "Y_4" "X_5"(向量化循環比對)
```

## 五、條件控制

```r
x <- 1

# if / else 完整寫法
if (x > 0) {
  y <- 5
} else {
  y <- 10
}

# 單行寫法
if (x > 0) y <- 5 else y <- 10

# 向量化版本，適合對整個向量做條件判斷
y <- ifelse(x > 0, 5, 10)

# if / else if / else
if (x == 0) {
  y <- 5
} else if (x > 2) {
  y <- 10
} else {
  y <- 3
}
```

### `switch()`:多分支選擇

```r
# 用「數字」指定要執行第幾個分支
switch(2, 10, 3 + 5, 3 / 3)   # 8 (執行第 2 個分支)

# 用「名稱」指定要執行哪個分支
switch("second", first = 1 + 1, second = 1 + 2, third = 1 + 3)  # 3
```

**`if/else` 與 `switch()` 的選擇**:條件式是「範圍判斷」(如大於小於)用 `if/else`;是「多選一的固定值/名稱對應」用 `switch()` 較簡潔。

## 六、迴圈結構

```r
# for：走訪固定序列，適合已知次數的重複
y <- 0
for (x in 1:10) y <- x + y   # 1 加到 10

# while：只要條件成立就持續執行
x <- 1; y <- 0
while (x <= 10) {
  y <- x + y
  x <- x + 1   # 務必遞增，否則無窮迴圈
}

# repeat：條件寫在迴圈內部，用 break 手動跳出
x <- 1; y <- 0
repeat {
  if (x > 10) break
  y <- x + y
  x <- x + 1
}

# next：跳過當次迭代剩餘程式碼，直接進入下一輪
x <- 1; y <- 0
repeat {
  if (x > 10) {
    break
  } else if (x == 5) {
    x <- x + 1
    next   # x = 5 不會被加總，但仍要遞增，否則卡在無窮迴圈
  }
  y <- x + y
  x <- x + 1
}
```

**三種迴圈比較**

| 語法 | 適用情境 | 跳出方式 |
|---|---|---|
| `for` | 已知要跑幾次(固定序列) | 序列跑完自動結束 |
| `while` | 不確定次數,但有明確持續條件 | 條件不成立自動結束 |
| `repeat` | 條件邏輯較複雜,想自由控制跳出時機 | 必須手動 `break` |

## 七、機率分布與亂數模擬

R 的機率分布函式有統一的字首規則,只要記住這四個字首,就能套用到任何分布:

| 字首 | 意義 | 作用 |
|---|---|---|
| `r` | random | 從分布中抽樣 |
| `d` | density | 給 x,求該點的機率密度(曲線高度) |
| `p` | probability | 給 x,求累積機率(≤ x 的機率) |
| `q` | quantile | 給機率,求對應的 x(是 `p` 的反函式) |

以常態分布為例:

```r
rnorm(1000, 5, 1)    # 抽 1000 個樣本，平均=5，標準差=1
dnorm(0)             # x=0 處的機率密度 ≈ 0.3989
pnorm(1.96)          # ≤1.96 的累積機率 ≈ 0.975
qnorm(0.975)         # 累積機率 97.5% 對應的 x 值 ≈ 1.96

# pnorm 與 qnorm 互為反函式
pnorm(1.96)   # 0.975（給 x 求機率）
qnorm(0.975)  # 1.96 （給機率求 x）
```

其他常用分布(套用相同的 `r/d/p/q` 規則):

```r
runif(100, 0, 1)      # 均勻分布
rt(100, df = 5)       # t 分布
rchisq(100, df = 5)   # 卡方分布
rexp(100, rate = 1)   # 指數分布
rbeta(100, 2, 5)      # Beta 分布
rgamma(100, 2, 1)     # Gamma 分布
```

### 直方圖與描述統計

```r
a <- rnorm(1000, 5, 1)
hist(a, nclass = 30)                                            # 分 30 組
hist(a, breaks = 30)                                            # R 自動調整成美觀組距
hist(a, breaks = seq(min(a), max(a), (max(a) - min(a)) / 30))   # 手動指定組距

y <- c(10.4, 5.6, 3.1, 6.4, 21.7)
var(y)                                     # 內建變異數函式
sum((y - mean(y))**2 / (length(y) - 1))    # 變異數的手動計算方式(驗證公式)
```

## 八、矩陣與陣列

### 建立方式

```r
x <- c(1, 2, 3); y <- c(4, 5, 6)

rbind(x, y)     # 依「列」合併
cbind(x, y)     # 依「欄」合併

array(x, c(2, 3))   # 建立 2x3 陣列

matrix(1:3, nrow = 3, ncol = 3)                 # 預設按「欄」填資料
matrix(1:3, nrow = 3, ncol = 3, byrow = TRUE)   # byrow=TRUE 改為按「列」填資料
```

也可以直接改變一個向量的 `dim` 屬性,讓它變成矩陣:

```r
x <- 1:20
dim(x) <- c(4, 5)                 # 轉成 4x5 矩陣
x <- array(1:20, dim = c(4, 5))   # 等效寫法
```

### 索引與屬性查詢

```r
w <- rbind(c(1,2,3), c(4,5,6))

w[1, ]      # 第 1 列，逗號後留空 = 所有欄
w[, 1]      # 第 1 欄
w[1, 1:3]   # 第 1 列的第 1~3 欄

dim(w); nrow(w); ncol(w); length(w)   # 維度資訊
t(w)                                   # 轉置(aperm(w) 效果相同)
```

### 具名列 / 欄

```r
mdat <- matrix(c(1, 2, 3, 11, 12, 13),
               nrow = 2, ncol = 3, byrow = TRUE,
               dimnames = list(c("row1", "row2"),
                               c("C.1", "C.2", "C.3")))

mdat["row1", "C.2"]   # 有命名時可直接用名稱索引，比數字索引更易讀
```

### 矩陣運算

```r
m <- matrix(sample(1:100, 9), 3, 3)

solve(m)      # 反矩陣
eigen(m)      # 特徵值與特徵向量
m %*% m       # 矩陣乘法(注意：* 是逐元素相乘，%*% 才是真正的矩陣乘法)
```

### 條件篩選與位置查詢

```r
a <- c(1, 2, 3, 4, 5)
which(a > 3)   # 回傳「符合條件的索引位置」，不是值 -> 4 5

aa <- c(94, 86, 18, 79, 28, 68, 7, 27, 84, 10)
quantile(aa, 0.3)                    # 第 30 百分位數
bb <- which(aa <= quantile(aa, 0.3)) # 找出低於該分位數的位置
aa_trimmed <- aa[-bb]                # 移除這些位置，達到「去除最低 30%」的效果
```
